SQL & Relational Databases

SQL Cohort Analysis & Customer Retention Optimization

Relational SQL data project implementing CTEs, window functions, and aggregations to calculate user retention rates and revenue degradation.

Core SQL Cohort Query 
WITH MonthlyCohorts AS (
    SELECT 
        customer_id,
        DATE_TRUNC('month', MIN(order_date)) OVER(PARTITION BY customer_id) AS cohort_month,
        order_date,
        total_amount
    FROM sales_orders
)
SELECT 
    cohort_month,
    COUNT(DISTINCT customer_id) AS active_users,
    SUM(total_amount) AS cohort_revenue
FROM MonthlyCohorts
GROUP BY cohort_month
ORDER BY cohort_month ASC;
